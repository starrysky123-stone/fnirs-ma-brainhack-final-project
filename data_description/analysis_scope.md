# Analysis Scope

## Main Focus

This project focuses only on morphological awareness (MA).

Although the original fNIRS task includes MA, PA, and Control conditions, the current final project will focus on MA-related brain activation.

## Participant Groups

Participants are divided into two grade-based groups:

- G1_3: children in grades 1 to 3
- G4_6: children in grades 4 to 6

The two groups are expected to differ significantly in age.

## Control Variables

The planned control variables are:

- word recognition
- IQ

These variables will be considered when interpreting group differences and may be included in the group-level statistical model if the required participant-level information is available in the analysis files.

## Planned Main Comparison

The main comparison will focus on:

- MA versus Control
- Group difference in MA-related activation between G1_3 and G4_6

PA will not be the main focus of the current analysis.

## Current Coding Decision

The raw data will not be modified.

The MATLAB pipeline may still load all stimulus conditions at the data-checking stage, but the later contrast analysis should be revised to focus on MA-related contrasts only.
