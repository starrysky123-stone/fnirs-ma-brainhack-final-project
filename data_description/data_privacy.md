# Data Description and Privacy Statement

## Data Source

The data used in this project come from a lab-based fNIRS study on children's language-related processing. The project focuses on the analysis pipeline rather than the public release of the raw dataset.

## Data Availability

The raw fNIRS data are not included in this GitHub repository because they involve human participant data and may contain sensitive or identifiable information.

## Privacy and Ethics

To protect participant privacy, the following files are not shared publicly:

- raw fNIRS data
- subject-level information
- participant demographic information
- files containing private metadata
- intermediate files that may contain subject-specific results

## Repository Policy

This repository only includes analysis scripts, documentation, project reports, slides, and non-sensitive output figures. The raw data folder is ignored using `.gitignore`.

## Reproducibility Note

Although the raw data are not publicly available, the analysis steps are documented so that the workflow can be understood and adapted to similar fNIRS datasets.
